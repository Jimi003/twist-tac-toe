Duel Tic-Tac-Toe

Both players pick a square at the same time. Pick the same one and it's rock-paper-scissors for it.

Each round both players secretly pick an empty square and a throw. Different squares: both marks land. Same square: a clash — rock beats scissors, scissors beat paper, paper beats rock. The winner takes the square, the loser places nothing that round, and a tie leaves the square open. Three in a row wins; if both complete a line in the same round, or the board fills up, it's a draw.
